# Original TyphoFormer Folder

This directory is kept separate from TyphoFormer++ to avoid mixing code and results.

It contains the original TyphoFormer scripts, original model files, assets, raw CSV, processed original data, and text embeddings copied from the bundled repository. TyphoFormer++ strict-6h data, leak-free baselines, and checkpoints live in `..\TyphoFormerPlus`.

The folder `archive_original_snapshot_from_interrupted_split/` is a redundant original-only snapshot preserved during the split cleanup. It is not used by the TyphoFormer++ experiments.
